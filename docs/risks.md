# 风险与应对

| 风险 | 影响 | 首选应对 |
|---|---|---|
| 网页私有 API 改变 | 全链路失效 | 传输层隔离、启动探测、固定协议记录、快速禁用插件 |
| PoW 算法变化 | 请求被拒 | 可替换 solver，优先跟随当前网页 worker；失败时返回明确错误 |
| Token/Cookie 失效 | 无法认证 | 健康检查和重新导入流程，不自动保存密码 |
| WAF、限流、账号风控 | 账号或服务受限 | 默认单并发、指数退避有上限、禁止绕过风控 |
| Web session 串话 | 数据错配 | MVP 每请求新 session，同账号串行 |
| SSE 事件变化 | 流式乱码或丢失 | 保留原始事件分类、未知事件告警、聚合器单测 |
| OpenAI 能力不等价 | 客户端误用 | 能力清单、明确 unsupported，不伪造 tools/structured output |
| 凭据泄露 | 账号风险 | 密钥链、日志脱敏、最小权限、无明文密码 |
| 许可与条款风险 | 项目不可发布 | 发布前复核 DeepSeek 条款、上游仓库许可和 CLIProxyAPI 插件许可 |

本项目不承诺绕过登录验证、WAF、速率限制或服务条款；发现上游禁止自动化时，应停止发布和使用相关适配。
