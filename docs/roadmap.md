# 里程碑

## M0：原型冻结

确认 CLIProxyAPI 目标版本、Plugin ABI、参考插件、授权边界和本机认证来源；完成本仓库文档评审。

## M1：只读骨架

建立独立插件模块、模型注册、配置 schema、健康检查和脱敏日志；不连真实网页接口时也能通过契约测试。

## M2：单请求文本链路

接入认证、PoW、创建 Web session、单次非流式 completion；覆盖 token 失效、challenge 失败和超时。

## M3：OpenAI 兼容流式

接入 SSE 解码、thinking 映射、取消、usage 和错误映射；用 CLIProxyAPI 真实端点完成手工验收。

## M4：稳定性与发布

增加并发保护、重试边界、协议探测、平台构建、版本清单和故障诊断；发布前只支持个人本机使用。

## M5：可选扩展

按真实需求评估 session 复用、文件/视觉、搜索和非严格工具调用。每项扩展必须单独定义上游协议证据与回退行为。
